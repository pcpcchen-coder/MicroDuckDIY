## C. 軸承、五金、線材與耗材

| 項目 | 整機／建議備料量 | 確認方式 |
|---|---:|---|
| 軸承，候選內16×外22×厚4 mm | 模型11；買12 | 先1顆量內外徑、厚度、配合座及轉動阻力，再整批；檔名與STL量測相符，仍非已驗證料號 |
| `configuration_default` 軸承 | 模型3；尺寸確認後買4 | 本次STL量得內10×外15×厚3 mm，作為候選尺寸詢價，先1顆試裝，非已確認供應商料號 |
| M2自攻螺絲 | 以馬達附贈及實際孔位為準 | ROBOTIS產品頁每顆含 M2×6 TAP 6支、M2×8 TAP 10支；這是包裝內容，**不是整機用量** |
| M2機械螺絲／螺母／墊片 | 建議4/6/8/10/12mm各20支打樣庫 | 工程備料量，正式數量和每孔長度待試裝；不要以機械牙代替塑膠自攻牙硬鎖 |
| 轉軸／墊圈／間隔套／舵盤及惰輪 | 待裝配确认 | 依XL330軸介面和CAD確認；可能需要FPX330配件但不能先假定整套需要15組 |
| 3-pin TTL馬達線 | 目標配置約16段＋3備品，長度待量 | 15馬達＋IMU＋控制器的樹狀連接規劃量；不同分支／轉接拓樸會改變段數。利用馬達隨附180mm線，試走線後再購短線 |
| HAT／IMU轉接線、電源線 | 各1套 | 查兩端pinout、間距、壓接端子，不能只看插頭外型；線材標上GND/V+/DATA |
| 硬質線材 | 建議1kg PETG或PLA+ | 試印＋失敗餘量，非模型淨耗材量；不需購買新印表機，可委外 |
| TPU 95A | 建議250–500g | 腳底與軟嘴共4件候選，需試摩擦及硬度；用量待切片 |
| 熱縮套管、束帶、標籤、泡棉、膠帶 | 各1包 | 接頭絕緣、應力釋放與線束標記；黏著物勿進軸承 |
| 支撐架／吊帶／軟墊 | 1套 | 可使用穩固現有治具；保留雙脚活動空間，禁止以桌邊直接測步行 |

螺絲長度選擇：先量被夾零件厚度、螺紋有效深度及盲孔底部餘量；從短螺絲試起，確認沒有頂到齒輪／電路。若沒有可驗證的孔深，先不鎖到底。正式裝配時逐孔記錄，形成自己的五金BOM。
