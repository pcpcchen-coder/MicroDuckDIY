# 03｜下載、切片與列印教學

本章為FDM打樣建議，未有實體列印驗證。官方RL資產是模擬／視覺網格；不保證封閉實體、孔徑公差或各部分可分離製造。

## 1. 準備來源

先看 [逐件清單](02-print-list.md)。固定版本及每個檔案SHA存於 `data/print-manifest.json`，不混用其他版本的腿、腳或外殼。資料夾所有STL不等於全部都要印。

```bash
# 在 MicroDuckDIY repo 根目錄執行，需 Python 3.10+
python3 scripts/prepare_prints.py --list
python3 scripts/prepare_prints.py --download --only bearing_roll motor_support
# 試装過後，再取全部30種候選
python3 scripts/prepare_prints.py --download
```

Windows可用 `py -3` 取代 `python3`。工具從原廠固定commit下載，驗證Git blob SHA，保留原始檔至 `build/prints/original/`，另輸出毫米版到 `build/prints/mm/` 與 `build/prints/report.json`。每種輸出1個檔案，切片時依清單複製數量；不是把所有零件合成一盤。預設不下載馬達、軸承等購買品模型。

## 2. 單位與尺寸

已直接檢查官方 `trunk_base.stl` 二進位座標：包圍盒約 **0.057×0.036×0.003 m**，也就是 **57×36×3 mm**。STL沒有單位欄位，常見切片軟體會當毫米讀入，造成小1000倍。

- 使用本工具輸出的 `mm/`：切片比例100%，不要再乘1000。
- 手動下載原檔：線性倍率1000倍，也就是百分比欄位100,000%；先確認軟體是否已自動轉換。別將1000%誤認為1000倍。
- 用卡尺與真實XL330外型交叉驗證孔距及馬達座；不能只看整鴨高度約25cm。
- 不要用縮放整台機器的方法修單個軸承孔，這會同時改變關節中心與步態幾何。

## 3. 建議第一版切片起點

| 項目 | 硬質結構件 | 外殼 | TPU腳底／軟嘴 |
|---|---|---|---|
| 噴嘴／層高 | 0.4mm／0.16–0.20mm | 0.4mm／0.16–0.20mm | 0.4mm／0.20mm |
| 材料 | PETG或PLA+試作 | PETG或PLA+ | TPU95A先試 |
| 外牆 | 4–5圈 | 3圈 | 3圈 |
| 上下層 | 5層起 | 4–5層 | 4層起 |
| 填充 | 30–40%起 | 15–20%起 | 15–30%起，依摩擦與壓縮試驗 |
| 支撐 | 僅必要處，避免軸承孔／配合面傷痕 | 依懸垂面 | 減少難拆內支撐 |
| 溫度／速度 | 依線材廠及機器設定 | 同左 | 依機器擠出系統調低速度 |

以上不是原廠材料規格。別全部100%填充：額外質量會改變RL動力學。先記錄實際重量，再判斷強度是否足夠。樹脂脆性與碎裂、PETG蠕變、PLA耐熱都需考慮；第一版室內低負載驗證，破裂就停用。

## 4. 擺放與網格檢查

1. 匯入毫米檔，查看切片軟體顯示尺寸是否合理。
2. 檢查是否封閉、是否有非流形邊、浮空小島、極薄壁及多個互不連接實體。工具僅校验雜湊與座標，沒有保證網格可製造。
3. 結構件選擇讓主要拉力不要單靠Z層間黏著的方向；軸承座與螺孔避免把關鍵公差面壓在粗糙支撐上。
4. 外殼保留相機、板卡、FPC與接頭拆裝空間；先不用膠把殼永久封起來。
5. `noenoeil` 等網格可能包含多個實體，先看切片預覽，數量按該檔完整幾何1份計，不自行重複乘眼睛數。
6. 留存切片專案3MF、機器與線材名稱、層高、牆數、方向、支撐、預估克數／時數。

## 5. 試裝順序

先馬達座與軸承座→一條腿→軀幹及頸→頭部。軸承應能正向裝入、轉動順暢且不鬆脫；過緊先確認孔偏差和方向，勿硬敲使殼裂開。必要時微調「孔位補償」，不要直接整件縮放。所有修改記錄修訂號及實測值。

每件記錄：檔名與SHA、數量、材料、列印重量、孔徑、裂痕、變形、組合干涉、通過／重印。腳底平放不可明顯翹曲；左右腳接地材料與厚度一致。相機及ToF窗口不能被不透光塑膠遮住。

## 6. 委外列印交付內容

交付毫米版STL、02章數量、材料要求與首件試裝順序；要求業者先回覆網格可列印性、方向、支撐接觸面、估計重量及報價。先做樣件，確認後再量產其餘。要求保留尺寸與孔位，未經確認不要整體縮放。原始3D模型來源及授權須隨資料附上；商業再散布／銷售另行確認授權。
