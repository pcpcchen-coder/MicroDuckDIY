# 05｜機構組裝、馬達編號與校正

> 路線 A：官方 alpha / Radxa 參考。本次要跟帆哥製作，請改讀 [路線 B（11–14章）](11-fange-start.md)，勿混用ID、列印比例與操作命令。

本章是按官方模型整理的施工順序，不是原廠逐螺絲安裝手冊。螺絲孔深、扭力、惰輪及部分軸承規格沒有完整製造資料；先試裝再補施工紀錄。來源：[官方robot_walk.xml](https://github.com/pollen-robotics/microduck_rl/blob/cb70b792312d559a4da09064d92009079671815f/src/mjlab_microduck/robot/microduck/robot_walk.xml)、[模型原始Onshape入口](https://cad.onshape.com/documents/804927696f06d877f3f1803e/w/5b75db19292e71970de02dee/e/ef6e972847fec8d82570b35e)。Onshape是來源連結，本次未驗證能否匿名編輯／匯出；無法開啟時仍可看MJCF定位資料。

## 1. 裝配前台架

1. 核對馬達型號、韌體、額定電壓，拍照建檔；首顆在5V限流台架上，用原廠Wizard設定工具辨識。
2. **只接一顆馬達**，出廠ID通常1、57,600bps。Torque off後改成下表ID及1Mbps，斷電重啟確認可讀。
3. 不接機構先測小角度、位置／電流／溫度回讀。不要把機構裝好後才全速搜尋方向。
4. 每顆貼ID與關節名，依序完成；不要把15顆預設ID1同時接到一條bus。
5. 全新整機不能依赖官方「自動替換一顆馬達」功能，該功能要求只缺一個關節。新組裝需要逐顆編ID。

runtime讀取角度為 `q = 2π × raw_position / 4096 − π`，raw2048对应0rad。實體的軸／支架必須跟模型座標相符；轉正向小角度後，在模擬和實機看同一關節是否同方向。嘴部是第15顆馬達，但行走policy只有14維動作，不能把所有ID重排以湊14個。

如果零位不一致，先確認軸組裝角度、Homing Offset及機構版本，逐顆保存原值及修改值；不要藉由修改home陣列掩蓋錯裝，否則觀測基準偏離訓練模型。未取得可靠機構對位資料的關節保留未驗收。

## 3. 分模組施工

| 順序 | 機構件／部位 | 做什麼 | 通過條件 |
|---|---|---|---|
| 1 | `trunk_base`、`power_support`、左右shell、`banana_pcb_locker` | 試組軀幹、電池位置與固定；先不封殼 | 無晃動，可拆電池，電源線不磨邊 |
| 2 | `yaw2roll`、`bearing_roll`、`hip_l` | 左右髖各一組，先裝軸承與髖馬達 | 兩側轉軸同軸、方向正確，無扭卡 |
| 3 | `upper_leg_left/right`、rigidity plate、`leg` | 各腿5軸，先左腿驗證再右腿 | 手動活動順暢，螺絲不頂軸／齒輪，線束有餘量 |
| 4 | `ankle_left/right`、`foot_left/right`、`sole_left/right` | 足踝及軟底，左右專用檔不鏡像猜造 | 平放不晃，兩側腳底摩擦一致 |
| 5 | `neck`×2、`neck_pitch`、`yaw_roll_motion` | 頸與頭部俯仰／偏航／滾轉 | 頭轉至預定行程不扯線 |
| 6 | `motor_support`、`jaw`、`jaw_soft`、`soft_mouth_top` | 嘴部機構及ID34 | 不夾線、不撞殼；先窄範圍測試 |
| 7 | `face_part`、上下head shell、`noenoeil`、`m12_lens_holder` | 試放板卡、相機、音訊及線 | 散熱、FPC、鏡頭及ToF視野都保留 |
| 8 | 整機 | 稱重，記錄電池位置，標示線束，最後封殼 | 仍可接設定器、斷電及拆修 |

同名`hip_l`在模型中用2次，不代表應另造`hip_r`。模型中的`pcb__raspberry_pi_zero_2_w`是舊幾何佔位，Radxa的接頭干涉要實際比對；不能假設裝入就有孔位完全相符。

## 4. 走線與關節驗收

断電、Torque off，沿每個關節預定工作範圍緩慢移動，線束不得成為機械限位。避免線貼住散熱區或夾在殼縫。電源與訊號接头逐腳量通斷；先拍開殼照片，再上支撐架通電。

每個關節用小於完整範圍的正負小步動作驗方向，觀察電流有無異常上升；若聲音、震動、壓降或發熱異常立即停止。先單顆，再單腿，最後15軸。手動無干涉不代表帶電一定無干涉，兩項分開驗。

## 5. IMU方向及重量

靜止時gyro接近0；直立時trunk重力方向應接近`[0,0,-1]`。各軸小幅轉動，記錄正負方向，確定沒有重複套用安裝旋轉。不可拿頭上／不同方向IMU的原始值不經轉換送入平衡policy。

將主控、電池、線材、殼、軟底都裝好再稱總重。記錄左右腳承重、電池位置與頭部重量；更換大電池、增加散熱塊或相機後需重驗。官方約800g僅供量級對照，不是任何800g的機器都可以共用策略。
