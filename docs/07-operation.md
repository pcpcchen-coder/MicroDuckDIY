# 07｜日常操作、維護與故障排除

> 路線 A：官方 alpha / Radxa 參考。本次要跟帆哥製作，請改讀 [路線 B（11–14章）](11-fange-start.md)，勿混用ID、列印比例與操作命令。

本章只適用於完成08章驗收、供電與控制相容的機器；按鍵以查核版本的官方cheatsheet為準。修改過手把bindings要以自己的設定為準。

## 每次開機

1. 查電池固定、殼裂、螺絲鬆動、電源接頭、腳底與腳邊雜物。
2. 放地面軟墊／支撐架，不在桌邊測；確認可以立即卸力及切斷馬達電源。
3. 開機後先`robotctl health`、`robotctl pad status`、`robotctl monitor`。
4. 支撐狀態確認home，腳底接地後短暫啟動站立策略，最後低速走動。
5. 記錄失敗時的版本、電壓、溫度與動作，不靠不斷重啟掩蓋故障。

## 手把速查

| 操作 | 查核版本功能 | 第一版使用建議 |
|---|---|---|
| Start第一次 | 啟用扭力，約2秒到home後保持 | 必須支撐 |
| Start第二次／後續 | 啟動／切換policy開關 | 停policy不等於卸力 |
| 左搖桿 | 前後／橫移 | 小幅輸入，先慢速 |
| 右搖桿 | 轉向 | 先原地小幅測 |
| Select短按後放開 | 卸力 | 會倒下；支撐架／地面測試時用 |
| Select長按2秒 | 坐下、卸力、關機 | 預留動作空間 |
| D-pad下 | 坐下／站起 | 穩定步行後再測 |
| Y／三角 | 頭部模式 | IMU手把配置開啟時行為不同 |
| B／圓圈 | 身體姿態模式 | 初期避免大角度 |
| RT／LT | 嘴部；另有音效 | 先確認夾持與嘴部限位 |
| A／叉 | 地面抓取 | G5後，先空載 |
| X／方塊 | 前滾翻；按住可連續 | 暫不測，衝擊較大 |
| LB／RB | 左／右踢 | 穩定後測 |
| D-pad上長按3秒 | 步行／輪滑切換 | 沒裝輪滑配件就不要切 |
| D-pad右 | 重啟馬達 | 先支撐卸力，排除故障再恢復 |

## 停止的三個層級

- **停止移動：** 放開搖桿／歸零命令；仍會保持姿態與出力。
- **卸力：** 支撐後用Select短按放開或`sudo robotctl robot relax --yes`；它會失去支撐而倒下。
- **電氣異常：** 冒煙、異味、過壓、卡死時用實體馬達電源切斷，不等待網路或GUI。這是保護動作，與日常關機不同。

正常結束：回平地→停動作→坐下／支撐→按正常關機流程→確認主控關閉後移除電池。不要平常都直接拔電池造成儲存損壞。零售DIY版充電走外接匹配充電器；官方量產有板上充電的說明不代表你自製的C1 HAT具有相同能力。

## 故障排除

| 現象 | 優先查 | 處理／驗證 |
|---|---|---|
| 全部馬達失聯 | 電源、共地、極性、TTL轉接、tty被占用 | 萬用表量供電；`fuser`查serial-getty；停止其他串口程式 |
| 只有一顆失聯 | ID、線、接頭、過載／溫度保護 | 斷電換線、單顆Wizard檢查；別直接提升電壓 |
| 全新15顆掃到異常 | 重複出廠ID1 | 一顆一顆編號再串接 |
| 5V電源顯示0%電池 | runtime的2S電壓假設 | 回到04章做電源／電量適配，並非換一顆電池就解決 |
| IMU有資料但站不穩 | 安裝軸向、SFLP新鮮度、零位 | 三軸慢轉測方向；檢查凍結／NaN；不可用常數假資料 |
| 一啟動就暴衝／扭轉 | 馬達ID、正負方向、軸對位錯誤 | 立即卸力回單關節台架；不反覆按Start |
| 上力Radxa重啟 | 瞬時壓降、共地回流、穩壓熱保護 | 示波器量主控及馬達軌；分清供電支路 |
| 站立抖動／發熱 | 卡死、PD增益、策略／供電不匹配 | 先排機械干涉與零位，再看控制；不盲目調高增益 |
| 50Hz持續掉tick | 線束／read時序／其他負載 | 查monitor与journal；IMU與servo是否都支援fast read |
| 手把配不上 | BLE廣播／配對模式／舊bond | 依上游`--pause-btd-on-pair`流程；不預設所有板都要`--weird-ble` |
| 相機黑畫面／方向錯 | FFC、驅動、實體方向、版本 | 斷電查線；依自己的安裝校方向，不直接抄固定旋轉值 |
| 更新後不健康 | 軟體或硬體缺失 | 先查health／journal；有前版再rollback；硬體斷線不能靠降版修好 |

## 維護

首次5分鐘與每次摔倒後查裂痕、軸承鬆動、螺絲、線皮及接頭。每次換電池／相機／打印材料都記重量變化。換馬達記錄型號與韌體；官方單顆自動替換只適用完整相容bus中恰好缺一顆的情境。不要在帶電狀態抽插TTL馬達線。
